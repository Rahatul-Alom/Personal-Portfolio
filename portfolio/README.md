# Rahatul Alom — Portfolio

React + Vite + Tailwind CSS v4.

    npm install
    npm run dev      # http://localhost:3000
    npm run build

**Edit content** in `src/data/portfolioData.ts`: set `github` / `linkedin`, project `liveUrl` / `repoUrl` / `caseStudyUrl`, and fill the Journey items. Links and sections with no real data are hidden automatically in production.

**Contact form:** set `VITE_FORM_ENDPOINT` (see `.env.example`) to receive messages via a form service; otherwise it falls back to `mailto:`.
